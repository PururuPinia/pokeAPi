# Demo de API de Pokémon

Aplicación Front-end que consume los datos de la [PokéAPI](https://pokeapi.co/) nativamente.

## Archivos y Estructura
* `index.html`: Estructura principal y contenedores semánticos.
* `CSS/styles.css`: Estilos visuales del buscador y las tarjetas.
* `js/app.js`: Lógica de peticiones (Fetch) y manejo del DOM.

## Uso
1. Abre el archivo `index.html` directamente en cualquier navegador o mediante una extensión como Live Server en VS Code.
2. Ingresa el nombre de un Pokémon (ej: *charizard*) o su ID (ej: *150*) en el input y presiona **Buscar**.
